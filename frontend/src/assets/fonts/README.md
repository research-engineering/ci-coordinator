# Lato font assets

Unmodified Latin and Latin-ext normal WOFF2 subsets for weights 400 and 700
from `@fontsource/lato@5.3.0`, distributed under OFL-1.1.

Source: [npm archive](https://registry.npmjs.org/@fontsource/lato/-/lato-5.3.0.tgz).
Archive integrity: `sha512-0WhF/4rhrw+ErIyneKvhHn2YAl+xf8GDtllgOgOzDmeaSlLQtjpChXaQOpWhG2BchQW0WJy2zLV12Hdg0ndOMw==`.
No package scripts are used. The original license is retained in `OFL.txt` and
as a legal comment in the emitted stylesheet so it accompanies the distributed
font bytes. The browser witness checks the built license and font load under CSP.
