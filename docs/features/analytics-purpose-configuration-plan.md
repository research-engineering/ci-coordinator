## Acceptance Inventory

- Current auth/CSRF, deny without data read/write, exact path/body/generation.
- Closed keys, duplicate mappings/categories, Unicode scalar/codepoint/UTF-8
  bounds, safe integer, body/query size, cardinality and bulkhead boundaries.
- CAS concurrent writers, durable same-operation lost response, substitution,
  generation replacement, transaction audit attribution and rollback.
- Revision-consistent map reads, missing versus empty, named/unknown/mixed
  analytics through the actual service/store path without a callback or restart.
- Exact response admission; add/remove/edit validation; save confirmation;
  retained uncertain command across same-scope views; session/scope fencing;
  responsive layout and keyboard accessibility.
- Raw response bytes: duplicate and escaped-equal keys, invalid UTF-8, lossy
  decimals, unsafe integers, malformed JSON and depth/node bounds. Positive
  whitespace/escape and safe-integer controls; invalid PUT retains uncertainty.
- Migration predecessor and resulting capability, native catalog facts, required
  runtime grants, denied PUBLIC/excess grants and missing-capability admission.
- Isolated native mutations remove the purpose requirement or bypass its catalog
  attestor; exact-cause and real-UoW witnesses must fail independently.
