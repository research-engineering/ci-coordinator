# Archive Operator Workspace Plan

Owner and design: [archive operator workspace](archive-operator-workspace.md).
This plan sequences one integrated product journey rather than independent
backend/UI scaffolds. Native acceptance remains pending until exact-head CI.

1. Freeze backend read and analytics outputs after the isolated writers return.
   Integrate shared routes, dependencies and composition; register proof owners
   and regenerate OpenAPI and TypeScript projections from their canonical owner.
2. Add schema-bound archive and analytics clients using existing bounded fetch,
   exact query/result binding, cancellation, no-store and session observation.
3. Add the analytics view, measured summary, bounded usage plot/table and
   explicit unsupported/partial/forecast states. Connect workflow/job filters
   and a signal-to-attempt drill-down without reproducing server policy.
4. Add retained history record/job/detail/gap browsing and separate repository
   policy/preview controls. Preserve pause/rescan behavior and explicit
   destructive confirmation; no automatic erasure or provider mutation.
5. Move account access to the sidebar with usable compact/mobile states and
   unchanged login recovery/logout. Keep the main header for the current task.
6. Author focused schema/component/native browser witnesses. Test unequal
   installation/repository IDs, late responses, null points, long labels,
   empty/sparse/partial history, permission expiry, keyset invalidation and
   preview-versus-mutation boundaries. No local behavioral suite is permitted.
   Include Unicode scalar/encoded-query limits, canonical nested mapping,
   forecast holdout microsecond boundaries and diagnostic pairing. Exercise the
   graph-to-record-to-job journey, stale dataset refusal, preserved return
   filters and per-period measurement support without issuing a mutation.
   After hard navigation/source prerequisites, collect independent read-only
   label, geometry, accessibility and overflow assertions with soft assertions.
   Every failure still fails the test; one bad label must not conceal a second
   accessibility defect until another full CI run. Stateful mutation preconditions
   remain hard barriers.
7. Run local static gates, one integrated independent review, then the native
   GitHub aggregate. Recheck only predicates invalidated by a material repair.
8. Squash-merge only the qualified exact candidate. Deploy an immutable artifact
   under existing Swarm authority and verify actual administrator login, navigation,
   archive reads and logout. Record external gaps without declaring readiness.

Global default editing, rich-detail payload admission and full statistical
erasure remain separate authority decisions under the archive backend design.
They are not silently activated by these controls. Forecast tariffs, durable
purpose-map configuration and cause-specific regression alerts remain in the
economics roadmap; unavailable evidence stays explicit in this delivery.
