   image. Keep plan processing, native version guard, permission arguments,

   Add negative sibling edges and preserve the production composition rule.

   Cover every current laboratory sibling and all seven tool-directory keys.

   non-root execution, unchanged portable proof and guaranteed cleanup.

   GitHub Full Check. Obtain one bounded independent review, resolve actual
   counterexamples and squash-merge only an exact green candidate.

isolation, and target code receives no new host authority. Native test success,
actual tool-manager provider conformance and production evidence are separate
claims; record any unavailable provider witness explicitly.
