# Operator Recovery And Feedback Implementation Plan

Owner: `ci-coordinator.operator-ui`.
Design: [Operator Recovery And Feedback](operator-recovery-and-feedback.md).

## Sequence

1. Retain the current workbench numeric domain in one Zod contract and preserve
   the transport's return algebra. Parameterize field boundary witnesses.
2. Add a native application rendering boundary with a static private fallback
   and explicit same-URL refresh. Do not introduce automatic command retries.
3. Associate scope fields with their own validation errors and keep the live
   region mounted. Verify invalid submission, correction, focus and valid scope.
4. Replace hover-only abbreviated identifiers with one native disclosure
   component in the existing workbench and economics consumers. Keep exact
   values, compact formatting and responsive wrapping.
5. Add component witnesses and extend existing Chromium keyboard, touch and
   narrow-reflow coverage. Use current fixtures and no test-only production API.
6. Bind new paths to the existing UI requirements and update documentation
   navigation. Run only static gates locally; execute behavioral proof in GitHub.
7. Review the frozen diff once, close concrete counterexamples and require
   exact-head Full Check before a squash merge. This batch grants no permission
   to activate the deferred webhook or change the pilot.

## Acceptance

- A render crash remains recoverable without exposing exception details or
  inventing the result of an interrupted mutation.
- Every invalid scope field is independently explained and associated; the
  admitted scope domain and no-network-before-admission property are unchanged.
- Every replaced abbreviation exposes the same complete identity using native
  keyboard/touch interaction without horizontal page overflow.
- Existing session, authority-revision, configuration and workflow journeys
  retain their behavior. No new runtime dependency or shared state layer appears.
- Route closure, native execution and production evidence remain distinct.
