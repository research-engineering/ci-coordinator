# Self-CI Pilot And Cost Qualification Plan

Status: active implementation and qualification plan.
Design: [self-CI pilot and cost qualification](self-ci-pilot-cost-qualification.md).
Independent review uses the current repository Agent Contract.

## Source Delivery

1. Retain the exact baseline run, source/tree, test population and per-phase
   timing evidence; do not sum enclosing and child phase clocks.
2. Prepare one real self-consumer artifact baseline per pytest process. Supply
   deep copies through a function-scoped fixture after current-owner validation.
3. Retain every existing assertion and parameterized case. Add falsifiers for
   copy isolation, stale owner inputs and same-path Go content admission.
   Mutation-input tests remain uncached.
4. Regenerate affected self-consumer and proof projections from their owners;
   retain exact source bindings and the current native test inventory.
5. Run scoped static checks, one frozen independent review and native GitHub
   qualification. Compare preserved test outcomes and setup/execution cost with
   the baseline; do not claim benefit from a point estimate alone if noise can
   explain it. Fix invalidated predicates together before another CI update.

## Connected Acceptance

6. Qualify and release the exact merged source through the existing manual
   release owner; deploy only the owned Swarm coordinator after compatibility
   and ACL preflight. Preserve other applications and their databases.
7. Resolve actual installation/repository bindings and signing public key;
   register non-enforcing policy through the existing API. Verify real administrator login,
   catalog visibility and same-subject plan exchange. Do not fabricate a key.
8. Cover ordinary, unknown, changed-control, mode/deletion and unavailable/stale
   plan cases through the existing bounded native corpus and representative
   live runs. Keep the independent native gate and label fallback explicitly.
9. Reconcile provider run/attempt, persisted measurements and UI/API views;
   distinguish measured CPU from runner occupancy and include orchestration cost.
10. Execute the scheduled-advisory route once against actual package and immutable
    image subjects. Validate receipts and the chosen notification route.

## Completion

Source merge does not close steps 6-10. Report each predicate as passed,
blocked or unverified with its source/run/release/deployment identity. Do not
expand the omission domain until the existing production-admission contract is
satisfied. An application-pilot target is a fallback pilot only for a demonstrated consumer-specific
blocker, never a substitute for missing common service authority.
